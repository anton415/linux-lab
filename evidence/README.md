# Evidence

Copy [TEMPLATE.md](TEMPLATE.md) to `<issue-number>-<topic>.md` for an actual run.
Publish a small reviewed record, not a terminal transcript. Keep raw output in
ignored `.local/` and inspect/redact it manually before extracting useful lines.

Record the exact revision and environment, command, exit/result, the original
hypothesis, a tested failure, recovery, and what Anton personally demonstrated.
`Not run`, `failed`, and `unknown` are valid outcomes. Never substitute expected
output for an observed result or imply a second machine was tested when it was not.

Use synthetic fixtures and lab aliases. Exclude secrets, private/public personal
addresses, host filesystem paths, account details, browser profiles, and budgets.
The template is not completed evidence and does not satisfy an issue by itself.
